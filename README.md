# ZAIDU portfolio

Static site (HTML/CSS/JS). Upload the folder contents to a GitHub Pages repo, e.g. `ZAIDU704.github.io`.

## Add your work
- **Content portfolio:** put files in `assets/images/`, then edit the `WORKS` list in `script.js` (set `src` and `alt`).
- **Projects:** add an entry to `PROJECTS` in `script.js`.
- Project previews are labelled "Conceptual Project Preview". Replace them with real screenshots only when you have them.

## Notes
- No phone or email is published. There is no contact form; a form needs a backend service (e.g. Formspree), which you can add later.
- `favicon.svg` is used as the icon; convert to `favicon.ico` if you want one.

## Local assets
`assets/icons` (Instagram, GitHub, app icon), `assets/images` (logo, social preview, touch icon), `assets/projects` (conceptual project previews). The site loads no external fonts, images or scripts, so it works offline. Add Space Grotesk by following the note at the top of `style.css`.
